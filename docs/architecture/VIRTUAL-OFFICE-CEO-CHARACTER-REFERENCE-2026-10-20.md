# Virtual Office — CEO / Brain Character Reference

## Shared visual direction

Use the repository image `1792476724975.jpg` as the canonical visual reference for the lead human character in the DGM-MAT virtual office. The character is the CEO / brain: a calm, experienced, approachable executive in a navy suit, white shirt and dark tie, with short grey hair and a grey beard.

## Role and boundaries

- Place the character in the highest-level executive / orchestration office.
- The character symbolizes system-wide oversight and coordination; it is not an autonomous authority bypassing DGM-MAT controls.
- Render only real DGM-MAT health, task, agent and approval state. Never fabricate agent activity or successful operations.
- Keep department boundaries and repository boundaries intact. This visual reference does not merge DGM-MAT with Sovereign Trader or any satellite repository.
- Reuse the same visual identity across desktop and mobile; adapt detail to device capability and retain a lightweight/chat-only fallback.
- Do not expose secrets, credentials or sensitive repository data in character panels.
