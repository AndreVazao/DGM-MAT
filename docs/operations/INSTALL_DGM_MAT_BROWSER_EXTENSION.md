# Install the DGM-MAT Chrome extension

The Windows distribution includes the unpacked extension under `browser_extension` and a one-click copy helper.

1. Extract the DGM-MAT Windows ZIP to a stable folder.
2. Run `scripts\install_browser_extension.bat`.
3. The helper preserves any previous extension folder under `%LOCALAPPDATA%\DGM-MAT\BrowserExtension.backups\`, then copies the new version to `%LOCALAPPDATA%\DGM-MAT\BrowserExtension`.
4. Chrome opens `chrome://extensions`. Enable **Developer mode**, choose **Load unpacked**, and select `%LOCALAPPDATA%\DGM-MAT\BrowserExtension`.
5. If that folder is already loaded, click **Reload** instead of loading a second copy.
6. Pair the extension using the one-time code generated by the local DGM-MAT.

The helper does not read browser cookies, passwords or tokens, does not close Chrome, and does not bypass Chrome's Developer mode or extension permission prompts. The previous extension folder is copied to a timestamped backup before replacement.
